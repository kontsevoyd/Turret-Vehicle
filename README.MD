# Turret Vehicle

Small Unity gameplay prototype created as a technical test assignment.

## Gameplay

- The vehicle moves forward automatically
- The player controls the turret horizontally
- Enemies approach and attack the vehicle
- Vehicle and enemies have health
- Win / Lose states with restart
- Enemies are spawned progressively as they approach the camera view
- Ground segments are generated dynamically during the level

## Controls

**Editor**

- Click to start / restart
- Drag mouse horizontally to rotate the turret

**Mobile**

- Tap to start / restart
- Swipe horizontally to rotate the turret

## Technical

- Unity 6000.3.15f1
- Projectile object pooling
- Progressive enemy spawning
- Procedural ground generation
- Simple component-based architecture
